Small Data Base

Source

A small database with a java swing gui. I wanted a place where I can store a media collection (books, movies, videos, games) with custom attributes like tags, ratings (own and external), length, author, wish-/watchlisted, etc. and the option to filter by them. Focus is on fast and extensive filtering. Not suited for larger data collecions, because whole collections is loaded into memory for faster filtering. Built in Java with Swing and mySQL. Project is currently not finished and has unfinished/not working features, because I'm working on transitioning to Spring Boot and a web frontend.
